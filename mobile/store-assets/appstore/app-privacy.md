# App Privacy answers (App Store Connect → App Privacy)

Matches `ios/BillingPOS/PrivacyInfo.xcprivacy` and the website privacy policy.

- **Do you or your third-party partners collect data from this app?** Yes
- **Tracking:** No data is used to track users.

For every data type below answer:

- Used for: **App Functionality** only
- Linked to the user's identity: **Yes**
- Used for tracking: **No**

| Category | Data type | What it is |
| --- | --- | --- |
| Contact Info | Name | Shop owner/staff names, customer names on bills |
| Contact Info | Email Address | Shop and customer email (optional) |
| Contact Info | Phone Number | Login mobile number, customer phone |
| Contact Info | Physical Address | Shop address, customer address (optional) |
| Identifiers | User ID | Account ID for the signed-in user |
| User Content | Photos or Videos | Shop logo / product image the user picks |
| User Content | Other User Content | Products, stock, bills, expenses |
| Purchases | Purchase History | Sales and bills recorded in the shop |

Not collected: location, health, financial info (card numbers are never entered), contacts, browsing/search history, diagnostics, usage data, sensitive info.

Privacy Policy URL: https://kdspoz.khisedigital.in/privacy-policy.html
